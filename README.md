# CC Bidding Project (2025)

## Quick Links

- See [`ONBOARDING.md`](./ONBOARDING.md) for setup and contribution guide.
- **Making changes?** All development work happens in `src/`:
  - Frontend pages: `src/app/**/page.tsx`
  - Backend APIs: `src/app/api/*/route.ts`
  - Database models: `src/lib/models/*.ts`

## Stack

- Next.js 16 (App Router)
- MongoDB (Atlas)
- TypeScript + Tailwind

## Commands

```bash
npm i          # Install dependencies
npm run dev    # Start dev server
```

See [`ONBOARDING.md`](./ONBOARDING.md) for environment setup, coding conventions, and MongoDB connection details.
